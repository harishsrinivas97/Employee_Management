# 👨‍💼 Employee Management System

🚀 **A simple and efficient web application to manage employee records using Python Flask and MySQL.**

## 📌 About the Project

The Employee Management System is designed to simplify employee data management within an organization. It allows managers to securely log in and manage employee information through a clean, modern, and user-friendly interface.

Managers can add new employees, view employee details, update existing records, and delete employee information. The application also includes email-based password reset functionality and manager-wise employee management.

## ✨ Key Features

- 🔐 **Manager Authentication** – Registration and login functionality.
- ➕ **Add Employees** – Store employee details such as name, department, salary, and phone number.
- 📋 **View Employees** – Display employee records managed by the logged-in manager.
- ✏️ **Update Employee Details** – Modify existing employee information.
- 🗑️ **Delete Employees** – Remove employee records when required.
- 📧 **Forgot Password** – Reset passwords through email verification links.
- 🗄️ **Database Integration** – Store and manage records using MySQL.
- 🎨 **Modern UI** – Clean and responsive interface built with HTML and CSS.
- 💬 **Flash Messages** – Display success and error notifications.

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask Framework
- 🎨 HTML5 and CSS3
- 🗄️ MySQL
- 📩 Flask-Mail
- 🔑 Session Management and ItsDangerous

## ⚙️ How to Run the Project

**1️⃣ Clone the repository**
```bash
git clone <your-repository-url>
```

**2️⃣ Navigate to the project directory**
```bash
cd employee_managment
```

**3️⃣ Install the required packages**
```bash
pip install flask mysql-connector-python flask-mail itsdangerous python-dotenv
```

**4️⃣ Configure the database**

Create the required MySQL database and tables, then configure your database connection and email settings.

**5️⃣ Start the application**
```bash
python app.py
```

**6️⃣ Open in your browser**

Visit `http://127.0.0.1:5000/` to access the application.
